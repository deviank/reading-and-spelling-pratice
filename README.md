# Reading & Spelling Buddy

A cheerful reading and spelling practice website for a 9 year old learner.

The app is intentionally simple: it is plain HTML, CSS, and JavaScript, with no
database and no build step. Progress is saved in the browser with `localStorage`.

## Features

- Short reading passages with comprehension questions.
- Spelling practice with clues, hints, and instant feedback.
- Browser speech playback for reading passages and spelling words.
- Progress counters for reading checks, spelling words, and correct answers.
- Mobile-friendly layout.

## Run Locally

Place this project folder at:

```text
C:\xampp\htdocs\reading-spelling-buddy
```

Then start Apache in XAMPP and open:

```text
http://localhost/reading-spelling-buddy/
```

## GitHub Pages

This project can be published directly with GitHub Pages because it is a static
site. After pushing to GitHub:

1. Open the repository on GitHub.
2. Go to `Settings`.
3. Go to `Pages`.
4. Set the source to the `main` branch and root folder.
5. Save.
